## 🌟 Overview

**GTC Solutions** is a modern, high-performance web application built with **Angular (Standalone Architecture)** and **Tailwind CSS**. It incorporates high-end corporate finance aesthetics and a **floating content design system** (glassmorphic navbars, floating statistic pills, interactive solution finders, floating quick-action docks, and smooth consultation modal dialogs).

## 🚀 Getting Started

### Prerequisites
- Node.js: `v20.x` or `v22.x`
- npm: `v10.x` or `v11.x`

### 1. Install Dependencies
```bash
npm install
```

### 2. Development Server
Run the local dev server:
```bash
npm start
```
Navigate your browser to `http://localhost:4200/`.

### 3. Production Build
Generate an optimized production build:
```bash
npm run build
```
Compiled production files are generated in `dist/gtc-solutions/browser`.
